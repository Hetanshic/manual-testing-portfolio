# SauceDemo Manual QA Testing Project

A self-directed manual testing project on [SauceDemo](https://www.saucedemo.com), a public e-commerce demo application, built to practice and demonstrate core QA skills: test planning, test case design, execution, and defect reporting.

## What I Tested

- **Login** — valid/invalid credentials, empty fields, locked-out account, case sensitivity
- **Product Listing** — display, sorting (name/price, ascending/descending)
- **Product Details** — individual product view
- **Cart** — add/remove items, badge count accuracy, persistence across navigation
- **Checkout** — customer info form validation, order overview, order completion, cancel flow
- **Logout** — session handling

## Skills Demonstrated

- Manual test case design (positive, negative, and boundary testing)
- Exploratory and structured test execution
- Defect identification and reporting with clear reproduction steps and severity rating
- Test documentation: test plans and summary reporting

## Results Summary

- **30** test cases executed — **28 passed**, **2 failed**
- **2** defects logged (1 Medium, 1 Low severity)
- No critical or blocking issues found in the core purchase flow

## About

This is a personal practice project, not client or company work — built to apply manual testing concepts hands-on ahead of applying for QA roles.
